A command center for all my projects

Private
Problem
With a dozen builds on the go, I was losing track.
Built
A live dashboard that updates the moment any project changes, and visibly flags the ones going quiet.
Result

How it works

  1. Every project keeps a short log of each work session
  2. Emerald watches those logs for changes
  3. Status and to-dos update the moment a file changes
  4. Projects that go quiet fade, so nothing is forgotten
