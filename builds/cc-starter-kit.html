What it does

Easy install

  • Open the folder in Claude Code and ask it to set you up.
  • Claude asks three plain questions and personalises everything.
  • Backs up any existing setup and merges, never overwrites.

A better way of working

  • A rulebook that keeps Claude focused on the real goal.
  • Plain-language replies, test-first habits and tidy plans built in.
  • A four-page handbook in the browser explains every tool and guardrail.

Cost guardrails

  • Blocks needless re-reading of files that have not changed.
  • Keeps helper agents small, limited and one at a time.
  • A status line shows how full the session is at a glance.

Memory between sessions

  • Saves a snapshot of where work stands before a long session ends.
  • Picks any project back up exactly where it stopped.
  • Includes skills for planning, debugging, prototyping and reviewing my own work.
