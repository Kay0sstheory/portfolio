A searchable library of everything I've saved on Instagram

Private
Problem
I'd saved over 6,000 Instagram posts full of ideas and tools, and could never find any of them again.
Built
It downloads every saved post, transcribes what's said, reads the text on screen, and matches each post to the project it could help.
Result
When I start building a feature, the right saved post shows up on its own. This site's design drew on it.

How it works

  1. Instagram's export lists every saved post
  2. Each post is downloaded, transcribed and its on-screen text read
  3. An AI summary is kept beside my own notes, never mixed
  4. Posts are matched to the features of each project I'm building
  5. The right post surfaces when I start that feature
